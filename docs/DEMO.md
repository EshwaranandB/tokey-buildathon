# Demo walkthrough

1. Open the Tokey React console and sign in with a provisioned dashboard session.
2. Open **Overview** to see authority totals and persisted financial activity.
3. Open **Agents** and **Authorities** to inspect bounded authority.
4. Open **Transactions** and select the captured Razorpay-backed record.
5. Open **Integrations → Razorpay** to see the verified Test Mode record.
6. Open **Integrations → OpenClaw** and **MCP** to see the runtime boundary.
7. Open **Webhooks** and **Receipts** to explain verified evidence and auditability.

For the denied-path narrative, use the selected public test: an electronics request outside the permitted supplement scope is denied before a provider call is allowed.
